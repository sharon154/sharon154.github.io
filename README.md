# Retro Developer Portfolio

A responsive retro-futuristic developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in your browser.

For the best development experience, use VS Code + Live Server.

## Customize

Search and replace:

- `YOUR NAME`
- `YOUR_DEV_ID`
- `YOUR COMPANY`
- `your.email@example.com`
- GitHub URL
- LinkedIn URL
- Project names/descriptions/links
- Experience dates

## Main files

- `index.html` — page structure/content
- `style.css` — retro visual design/responsive layout
- `script.js` — typewriter, cursor glow, mobile menu and scroll animations

No framework is required.
